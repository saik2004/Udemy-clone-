# Udemy Clone

A responsive front-end clone of the Udemy website homepage, built to practice core HTML and CSS concepts — especially Flexbox layouts.

## 🔗 Live Demo
https://saik2004.github.io/Udemy-clone-/

## About the Project
This project recreates key sections of the Udemy homepage, including a sale banner and a recommended courses section with multiple course cards. It was built as a hands-on exercise to strengthen my understanding of layout techniques in CSS.

## Built With
- **HTML5** – semantic structure and content
- **CSS3** – styling and layout
  - Flexbox (`display: flex`) for card and container layouts
  - Custom classes (BEM-style naming, e.g. `Recomended__container`, `Courses__card`)

## Features
- Sale banner section
- Recommended courses grid using Flexbox
- Course cards displaying image, title, instructor, rating, and pricing (with strikethrough for discounted price)
- Clean, reusable component structure for course cards
## What I Learned
- Structuring a real-world layout using Flexbox
- Organizing reusable UI components (course cards) with consistent class naming
- Debugging deployment issues with GitHub Pages (relative image paths, case sensitivity, file uploads via Git)

## Next Steps
- Add responsiveness for mobile/tablet using media queries
- Convert static cards into dynamic components (React)
- Add hover effects and interactivity with JavaScript
